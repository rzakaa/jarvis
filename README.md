# Inhibitor korozji – receptura

Cel: stabilna receptura inhibitora korozji (koncentrat), bez rudawego zabarwienia wody z próbkami metalowymi.

## Dostępne składniki
- kwas sebacynowy
- molibdenian sodu
- BTA (benzotriazol)
- HEDP 60%
- polikarboksylat 445
- Rokamer 2100
- biocyd: CMIT (brak BIT)
- neutralizacja: NaOH lub KOH

## Problemy z poprzednich prób
- niestabilność koncentratu
- woda z próbkami metalowymi robiła się rudawa (korozja stali/żeliwa)

## Zadanie
Opracować recepturę z obliczeniami stechiometrycznymi (neutralizacja NaOH/KOH, pH, % mas.).
